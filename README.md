# 🌐 Personal Portfolio – Benjir Ahammed Sabbir

A modern, responsive personal portfolio website built to showcase my projects, skills, and background in **Data Science and Machine Learning**.  
This portfolio reflects my journey as a final-year CSE student at **Faridpur Engineering College**, and my passion for analyzing complex data, developing intelligent models, and building meaningful digital solutions.

---

## 🚀 Features

- 🎨 **Modern UI/UX** — Clean and minimal design built with HTML, CSS, and JavaScript  
- 📱 **Responsive Layout** — Optimized for mobile, tablet, and desktop devices  
- 🧠 **Project Showcase** — Filterable gallery to highlight my featured projects  
- 📬 **Contact Form** — Integrated email submission system using [Formspree](https://formspree.io)  
- 🌙 **Dynamic Navigation** — Smooth page transitions using `data-page` and `data-nav-link` attributes  
- ⚡ **Fast Loading** — Lightweight static site, deployable anywhere (GitHub Pages, Netlify, or Vercel)
